## Platform

web

## Users

Home seekers browsing properties and property owners publishing listings are equally important audiences (confirmed by the user).

## Product Purpose

The application lets seekers browse and filter property listings, view details and map locations, save favorites, and contact sellers. Signed-in owners can create and manage listings.

## Capabilities and Constraints

- React and Vite application using Clerk for authentication and Supabase for property data.
- English and Arabic locale switch with document direction handling.
- Dark mode and mobile layouts are supported.
- The service area, pricing model, listing verification policy, and exact rent-to-own proposition remain undecided. See `BUSINESS_GAPS.md`.
